# Economy Temp Check — published site

Build output. Do not edit by hand: every file here is regenerated by
`../export.py`, which renders the same templates the live Flask app uses so the
two cannot drift.

| file | what it is |
| --- | --- |
| `index.html` | the grid — 42 series, calendar quarters, sourced from SEC filings |
| `sources.html` | per-series metric definitions, latest filing, extraction rule |
| `economy_temp_check.csv` | the same numbers, flat |

Rebuild and publish from the project root:

```powershell
py -3.10 economy-temp-check\export.py
.\economy-temp-check\publish.ps1
```

`update.py` (weekly scheduled task) rebuilds these files on every run, so
publishing is only ever a commit and a push.
